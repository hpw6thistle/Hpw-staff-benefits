特約商店資料維護

使用 Excel 批次編輯商店。匯入與檢查都在目前的瀏覽器完成；替換並重新部署 data.js 後，查詢頁才會更新。

1. 匯出並用 Excel 編輯

  1. 下載目前資料或空白範本。Excel 請使用「資料 → 從文字/CSV」匯入，以 UTF-8 讀取，將門市 ID、電話、優惠碼及有效期限欄設為文字，避免開頭的 0 被省略或日期改格式。
  2. 每列填一個優惠，保留標題列。「適用職級」留空代表通用；同一間門市有職級專屬優惠時，複製該列、沿用門市 ID，再填入職級與優惠條件。同一門市的同一職級只能有一列。
  3. 「集團品牌」和「範例資料」填「是」或「否」。確認優惠及公開權限後，再把範例改為正式資料。
  4. 編輯後另存為「CSV UTF-8（逗號分隔）」，再於下方匯入。下載的檔名可自行調整。
