免安裝、跨裝置的員工專屬福利查詢網頁，手機與電腦皆可直接開啟使用。

核心功能

• 職級篩選：在搜尋列旁選擇您的「員工職級」，系統會顯示您適用的方案。
• 條件搜尋：可輸入店名、優惠內容或地址關鍵字，搭配「類別」與「地區」過濾符合的特約商店。
• 一鍵複製：點擊門市卡片上的複製按鈕即可帶走專屬代碼或提供公司統編。
• 一鍵開啟：點擊卡片上的「地圖」按鈕，可直接查看門市位置並規劃路線。

使用提醒

• 有效期限：期限以台灣時間計算（到期當日仍可使用）；若顯示「已到期」，系統將自動停用該筆代碼的複製功能。
• 現場核驗：網頁職級選單僅供查詢比對，實際至門市消費兌換時，請依公司規定出示員工證或相關證明核驗資格。
